Connexion bot

Configure l'URL de ton bot Render pour connecter le dashboard en live.

🔌 URL du bot
URL Render
📋 Instructions
1. Remplace server.js par le nouveau fichier livré.
2. Dans index.js, ajoute ces 3 lignes dans l'event ClientReady :
const srv = require('./server');
srv.setClient(client);
srv.setDb(db);
3. Ajoute dans .env (optionnel, moonthebest par défaut) :
DASHBOARD_SECRET=moonthebest
4. Redémarre le bot sur Render.
5. Entre l'URL ici et clique Tester.
